🧾 Employee Payroll System (Java)

A simple Employee Payroll System built using Object-Oriented Programming (OOP) principles in Java.

🚀 Features

✅ Abstract Employee class
✅ FullTimeEmployee and PartTimeEmployee subclasses
✅ Salary calculation using method overriding
✅ Add, remove, and display employees
✅ Terminal-based interaction
✅ Uses Encapsulation, Abstraction, Inheritance & Polymorphism

💰 Salary Logic

Full-Time: Fixed monthly salary
Part-Time: Hours Worked × Hourly Rate

🛠️ Technologies

Java
OOP Principles
ArrayList (Java Collections Framework)

🎓 Purpose

Designed to understand real-world implementation of OOP concepts in Java.
